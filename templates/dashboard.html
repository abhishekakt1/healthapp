🔄 Reclassify Document

Fix a document that was saved under the wrong type — e.g. a prescription mistakenly extracted as a lab report, or vice versa. Enter the Document ID (visible on each card as #ID), choose the correct type, and re-run extraction.

🔬 Lab Data Tools

Fix duplicate test names and remove erroneous test rows from the database.

🔄 Re-apply Canonical Names to All Existing Data

Run this after any fix to rename rules. Re-maps all existing test rows in the database using the latest alias table — fixes mislabelled tests like eAG→Average Blood Glucose, Glucose (Fasting) errors, etc.

🔀 Merge Duplicate Tests

Rename all rows of one test name to another — e.g. merge "T4" into "T4 Total (Thyroxine)".

🗑️ Delete Test Row

Remove all data for a specific test name — e.g. delete the spurious "Liver" row.

⚠️ Danger Zone

Permanently deletes all lab reports, prescriptions, and uploaded files. User accounts are kept. This cannot be undone.

  1. In Google Cloud Console → enable Sheets API and Drive API.
  2. Go to IAM → Service Accounts → create one → download the JSON key.
  3. Create (or open) a Google Spreadsheet. Share it with the service-account e-mail (give Editor access).
  4. Copy the Sheet ID from the URL:
    …/spreadsheets/d/SHEET_ID/edit
